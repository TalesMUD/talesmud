## What is TalesMUD?

TalesMUD is a modern multi-user dungeon (MUD) game that combines classic text-based adventure gameplay with a modern graphical interface. Explore a rich fantasy world, complete quests, battle monsters, collect items, and level up your character.

## Getting Help

- Use the `/help` command in-game for quick assistance
- Check this documentation for detailed information
- Look for the "More" button in the action bar for additional commands

Happy adventuring!
