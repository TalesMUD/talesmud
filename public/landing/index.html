Open-source game framework

TalesMUD

A framework for browser MUDs, DOOR-style games, and other text MMOs. Worlds, rules, and art ship as content packs. This repository is the engine.

  • Rooms, NPCs, items, dialogs, quests, and combat
  • Lua scripting and a creator UI
  • Web client and an optional DOOR presentation

Run the server, then open the play client. Set LANDING_PATH to this directory to serve the page at the site root.

Engine docs are in the repository: README.md, ARCHITECTURE.md, and FEATURES.md.
