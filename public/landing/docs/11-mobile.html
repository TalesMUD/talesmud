    Mobile Play Guide

    Play TalesMUD on your phone or tablet with the mobile-optimized interface.

    Mobile Interface Overview

    TalesMUD automatically adapts to mobile devices with a responsive, touch-friendly interface.

    Automatic Detection

    The client detects:
    • Screen size (small width triggers mobile layout)
    • Touch capabilities
    • Device orientation
    • Safe areas (notches, home bars)
    What Changes:
    • Layout switches to mobile mode
    • Widgets stack vertically
    • Tab-based navigation appears
    • Touch targets enlarged

    Mobile Layout

    Tab System

    The main interface uses tabs to switch between views:

    Room Tab:
    • Shows Room Widget
    • Current location display
    • NPC/enemy cards
    • Room actions
    Console Tab:
    • Shows Terminal
    • Command input
    • Game messages
    • Classic MUD interface
    Switching:
    • Tap "Room" or "Console" tab
    • Swipe between tabs (if supported)
    • Active tab highlighted

    Header

    Mobile Header Shows:
    • Current room name
    • Game status
    • Settings button
    • Menu button (if applicable)
    Always Visible:
    • Fixed at top of screen
    • Quick reference to location
    • Access to key functions

    Bottom Sheets

    Character/Inventory/Equipment:
    • Accessible via drawer system
    • Swipe up from bottom to open
    • Tap outside to close
    • Smooth animations
    Quest Log:
    • May be in drawer
    • Or accessible via menu
    • Tap to expand quests
    • Compact display

    Action Bar

    Mobile-Optimized:
    • Larger touch targets (44px minimum)
    • Wraps to multiple rows if needed
    • Clear button spacing
    • Tap-friendly design
    Same Functions:
    • Direction buttons
    • Standard commands
    • Combat commands
    • Room actions

    Touch Controls

    Touch Targets

    Minimum Size:
    • 44x44 pixels for all buttons
    • Comfortable tap area
    • Prevents mis-taps
    • Accessibility compliant
    Spacing:
    • Adequate gaps between buttons
    • Prevents accidental taps
    • Finger-friendly

    Gestures

    Supported Gestures:
    • Tap - Select, activate
    • Swipe - Switch tabs, scroll
    • Pull - Refresh (if implemented)
    • Pinch - Zoom (may not be supported)
    Standard Scrolling:
    • Swipe to scroll in terminal
    • Scroll room descriptions
    • Scroll inventory lists

    Keyboard

    On-Screen Keyboard:
    • Appears when tapping terminal input
    • Auto-capitalizes commands (may vary)
    • Auto-correct may interfere (can disable)
    • Takes significant screen space
    Tips:
    • Use buttons when possible
    • Type only when necessary
    • Dismiss keyboard to see more

    Mobile-Specific Features

    Room Text Overlay

    Always Enabled on Mobile:
    • Displays messages over room image
    • Easier to read than terminal
    • Auto-fade after duration
    • Bold text support
    Why:
    • Limited screen space
    • Better visibility
    • Quick glance information
    • No need to switch to console tab

    Compact Layout

    Vertical Stacking:
    • All widgets stack vertically
    • Full-width display
    • Scroll to see all
    • No side-by-side panels
    Priority:
    • Most important info first
    • Action Bar always accessible
    • Easy navigation

    Safe Area Handling

    Device Notches:
    • UI respects safe areas
    • No content behind notches
    • No content behind home indicator
    • Proper padding applied
    Automatic:
    • Detects device features
    • Adjusts layout
    • No configuration needed

    Playing on Mobile

    Navigation

    Movement:
    • Tap direction buttons (N, E, S, W, Up, Down)
    • Larger, easier to tap
    • Clear visual feedback
    Alternative:
    • Switch to Console tab
    • Type direction commands (n, s, e, w)
    • Faster for experienced players

    Combat

    Touch-Friendly Combat:
    • Tap "Attack" on enemy card to start
    • Tap "Attack", "Defend", or "Flee" buttons
    • Large combat buttons
    • Easy to react quickly
    Visual Feedback:
    • Character widget glows red
    • HP bar updates
    • Clear combat messages

    Inventory Management

    Grid View Recommended:
    • Easier to tap icons
    • Visual recognition
    • Thumb-friendly
    Actions:
    • Tap item to see details
    • Popup with large action buttons
    • Equip, Use, Drop clearly labeled

    Quest Tracking

    Mobile Quest Log:
    • Compact display
    • Tap to expand quest
    • Objectives clearly shown
    • Progress visible
    Notifications:
    • Toast style
    • Appear at top or bottom
    • Auto-dismiss
    • Important updates highlighted

    NPC Interaction

    Dialog on Mobile:
    • Full-screen dialog overlay
    • Large text
    • Clear option buttons
    • Easy to read and tap
    Trading:
    • Drawer or full-screen view
    • Easy item selection
    • Clear buy/sell buttons
    • Price visibility

    Mobile Layout Optimization

    Portrait Mode (Vertical)

    Default Orientation:
    • Vertical stacking
    • Tabs at top
    • Action Bar accessible
    • Scrollable content
    Best For:
    • One-handed play
    • Comfortable holding
    • Reading text

    Landscape Mode (Horizontal)

    Wider Layout:
    • May show side-by-side panels
    • More desktop-like
    • Better for typing
    • More visible at once
    Best For:
    • Two-handed play
    • Keyboard use
    • Desktop-style experience

    Rotation

    Auto-Adjust:
    • Layout adapts to orientation
    • Widgets reflow
    • Maintains usability
    Lock Orientation:
    • Use device settings
    • Prevent rotation
    • Consistent experience

    Mobile Settings

    Recommended Mobile Settings

    Interface:
    • Parchment Background: Off (cleaner on small screen)
    • Compact Mode: On (more info visible)
    • Room Text Overlay: On (automatic, helpful)
    Terminal:
    • Font Size: Medium or Large (readability)
    Layout:
    • Use default mobile layout
    • Don't over-customize on small screen
    • Keep essential widgets only

    Performance on Mobile

    Optimize:
    • Close background apps
    • Ensure good internet connection
    • Use Wi-Fi when possible
    • Clear browser cache periodically
    Battery Life:
    • Lower screen brightness
    • Disable unused features
    • Close when not playing
    • Consider power-saving mode

    Mobile Tips and Tricks

    Efficiency Tips

    Use Buttons Over Typing:
    • Faster than keyboard
    • No typos
    • Larger targets
    • Better flow
    Command History:
    • If typing, use history
    • Repeat commands easily
    • Save time
    Widget Priority:
    • Keep Action Bar visible
    • Room or Console tab primary
    • Access others via drawers

    Common Mobile Challenges

    Small Screen:
    • Solution: Use compact mode
    • Solution: Hide unused widgets
    • Solution: Use tabs effectively
    Fat Fingers:
    • Solution: 44px buttons help
    • Solution: Use landscape for more space
    • Solution: Use stylus if needed
    Keyboard Coverage:
    • Solution: Minimize typing
    • Solution: Use buttons primarily
    • Solution: Dismiss keyboard when done
    Battery Drain:
    • Solution: Lower brightness
    • Solution: Close when inactive
    • Solution: Use power-saving mode

    Advanced Mobile Play

    External Keyboard:
    • Connect Bluetooth keyboard
    • Type commands faster
    • Desktop-like experience
    • Still use touch for selections
    Tablet Play:
    • Larger screen = more space
    • May use desktop layout
    • Better for long sessions
    • Keyboard or touch

    Mobile Browser Recommendations

    Recommended Browsers

    iOS:
    • Safari (best compatibility)
    • Chrome (alternative)
    • Firefox (alternative)
    Android:
    • Chrome (best compatibility)
    • Firefox (alternative)
    • Samsung Internet (alternative)
    Tips:
    • Keep browser updated
    • Clear cache if issues
    • Enable JavaScript
    • Allow localStorage

    Browser Settings

    Enable:
    • JavaScript
    • LocalStorage
    • Cookies (for session)
    Disable:
    • Aggressive ad blockers (may break features)
    • Script blockers
    • Privacy modes that clear data

    Home Screen App

    Add to Home Screen: iOS Safari:
    1. Tap Share button
    2. Select "Add to Home Screen"
    3. Name it "TalesMUD"
    4. Tap Add
    Android Chrome:
    1. Tap menu (⋮)
    2. Select "Add to Home Screen"
    3. Name it "TalesMUD"
    4. Tap Add
    Benefits:
    • Quick access
    • Full-screen mode
    • App-like experience
    • No browser UI

    Mobile-Specific Commands

    Same commands work on mobile:
    • All movement commands
    • All information commands
    • All combat commands
    • All interaction commands
    Just use buttons for easier access!

    Troubleshooting Mobile

    "Layout looks wrong"

    Solutions:
    • Reload page
    • Clear browser cache
    • Rotate and rotate back
    • Reset to default layout

    "Buttons too small"

    Check:
    • Compact mode off
    • Browser zoom level
    • Device accessibility settings
    • Screen size adequate

    "Keyboard won't appear"

    Solutions:
    • Tap input area in Console
    • Check browser permissions
    • Restart browser
    • Update browser

    "Game runs slow"

    Optimize:
    • Close other apps
    • Clear browser cache
    • Free device memory
    • Check internet connection
    • Disable unused features

    "Touch not responding"

    Check:
    • Screen protector not interfering
    • Clean screen
    • Browser up to date
    • Device not overheating
    • Restart browser

    Data Usage

    TalesMUD is text-based:
    • Very low data usage
    • ~1-5 MB per hour (estimate)
    • Safe on mobile data
    • Minimal downloads
    Save Data:
    • Images load once (cached)
    • Text is lightweight
    • WebSocket efficient

    Mobile vs Desktop

    Mobile Advantages

    Pros:
    • Play anywhere
    • Touch-friendly
    • Casual gaming
    • Quick sessions

    Mobile Limitations

    Cons:
    • Smaller screen
    • Keyboard slower
    • Battery concerns
    • Less info visible at once

    Best of Both

    Use Mobile For:
    • Quick check-ins
    • Light questing
    • Simple tasks
    • On-the-go play
    Use Desktop For:
    • Long sessions
    • Complex tasks
    • Fast typing
    • Multiple widgets

    Mobile Play Checklist

    Before Playing on Mobile

    • [ ] Good internet connection (Wi-Fi preferred)
    • [ ] Device charged or charging available
    • [ ] Browser updated
    • [ ] Site added to home screen (optional)
    • [ ] Settings optimized for mobile
    • [ ] Comfortable grip position

    During Mobile Play

    • [ ] Use buttons instead of typing
    • [ ] Switch between tabs as needed
    • [ ] Monitor battery level
    • [ ] Take breaks (small screen = eye strain)
    • [ ] Save progress frequently (auto-save helps)

    Mobile FAQs

    Q: Can I play offline?

    A: No, TalesMUD requires internet connection.

    Q: Does it work on tablets?

    A: Yes! Better experience due to larger screen.

    Q: Can I play on a Chromebook?

    A: Yes, works like desktop in browser.

    Q: Touch or stylus?

    A: Both work, personal preference.

    Q: Can I use external keyboard?

    A: Yes, Bluetooth keyboards work great.

    Q: Landscape or portrait better?

    A: Personal preference. Try both!

    Q: Does it drain battery fast?

    A: No, text-based game is very efficient.

    Q: Can I switch between mobile and desktop?

    A: Yes, settings sync via localStorage per-browser.
