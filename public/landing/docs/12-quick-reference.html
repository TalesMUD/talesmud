    Quick Reference Guide

    Fast lookup for commands, shortcuts, and essential information.

    Essential Commands

    Command Description
    n, s, e, w Move north, south, east, west
    up, down Move vertically
    look Examine current room
    i View inventory
    eq View equipment
    c View character stats
    pickup [item] Pick up item
    drop [item] Drop item
    use [item] Use/consume item
    equip [item] Equip item
    unequip [item] Remove equipped item
    talk [npc] Talk to NPC
    attack [enemy] Start combat
    flee Escape combat
    list View merchant inventory
    who List online players
    help Get help

    Combat Commands

    Command Use When
    attack Deal damage (primary action)
    defend Reduce incoming damage (low HP)
    flee Escape combat (losing badly)
    status Check combat state
    use [potion] Heal or buff

    Widget Shortcuts

    Widget Purpose
    Room See location, NPCs, description
    Terminal Type commands, see messages
    Action Bar Quick commands and navigation

    Inventory Items you're carrying

    Settings Quick Access

    General:
    • Sound Enabled: Toggle audio
    • Music Volume: 0-100
    • SFX Volume: 0-100
    Interface:
    • Parchment Background: Texture on/off
    • Compact Mode: Dense layout
    • Room Text Overlay: Messages on room

    Recommended Settings

    New Players:
    • Parchment: On
    • Compact: Off
    • Room Overlay: On
    Experienced Players:
    • Parchment: Off
    • Compact: On
    • Room Overlay: Off (optional)
    Mobile:
    • Compact: On
    • Room Overlay: On (automatic)

    Survival Tips

    Always:

    • Carry 10+ healing potions
    • Keep HP above 50% between fights
    • Save gold for equipment upgrades
    • Complete quests at your level
    • Set bind point in safe location

    Never:

    • Fight enemies 3+ levels above you without preparation
    • Explore dangerous areas without potions
    • Ignore HP warnings
    • Waste gold on low-quality items
    • Forget to equip better gear

    Item Management

    Keep:

    • Equipment upgrades
    • Healing potions (stock)
    • Quest items
    • High-quality gear

    Sell/Drop:

    • Outgrown equipment
    • Low-quality duplicates
    • Excess consumables
    • Vendor trash

    Quest Efficiency

    1. Accept all quests in an area
    2. Group by location
    3. Complete objectives together
    4. Return to turn in batch
    5. Move to next area

    Combat Strategy

    Enemy Level Strategy
    3+ below Quick attack spam
    1-2 below Attack, minimal potions
    Same level Attack + defend, use potions
    1-2 above Careful, defend often, stock potions
    3+ above Flee or avoid

    Level Progression Priority

    1. Complete quests (best XP)
    2. Fight at-level enemies
    3. Upgrade equipment
    4. Explore new areas
    5. Grind only if necessary

    Gold Priority Spending

    1. Equipment upgrades (biggest impact)
    2. Healing potions (survival)
    3. Quest requirements (progress blockers)
    4. Consumable buffs (optional)
    5. Cosmetics (luxury)

    Minimap Tips

    • Resets on page reload (session storage)
    • Shows current floor only
    • Nearby rooms fade by distance
    • Hover for room names
    • Use for navigation reference

    Mobile Quick Tips

    • Use buttons > typing
    • Tap between Room/Console tabs
    • 44px touch targets
    • Portrait or landscape (preference)
    • Add to home screen for app feel

    Troubleshooting Quick Fixes

    Problem Quick Fix
    Lost Check minimap, type look
    Low HP Use healing potion immediately
    Can't move In combat? Type flee
    Inventory full Sell items to merchant
    Dialog stuck Complete selection (type number)
    NPC won't talk Check it's not enemy type
    Layout broken Clear localStorage, reload
    Settings won't save Check browser privacy settings

    Resource Management

    HP Management:
    • Use potions at 30-40% HP
    • Rest between fights
    • Keep emergency potions
    Gold Management:
    • Save for equipment
    • Don't splurge on consumables
    • Sell unnecessary items
    Inventory Management:
    • Keep 5-10 free slots
    • Sell old equipment
    • Stack consumables

    Time Efficiency

    Fast Leveling:
    • Quest-focused (best XP/time)
    • Fight at-level enemies
    • Avoid grinding low-level mobs
    Fast Gold:
    • Sell equipment drops
    • Complete quests (rewards)
    • Merchant rare items
    Fast Travel:
    • Type directions (faster)
    • Learn major routes
    • Use minimap
