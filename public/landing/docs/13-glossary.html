    Glossary

    Common terms and definitions used in TalesMUD and MUD gaming.

    A

    Action Bar

    : The widget containing quick-access buttons for commands, navigation, and actions.

    Agility

    : Character attribute affecting attack speed, dodge chance, and critical hit rate.

    Armor

    : Equipment that reduces damage taken. Also refers to the Armor stat that provides damage reduction.

    Attribute

    : A character statistic (Strength, Intelligence, etc.) that affects gameplay mechanics.

    B

    Bind Point

    : The location where your character respawns after death. Set with the bind command.

    Boss

    : A powerful enemy with high HP, strong attacks, and exceptional loot. Often unique and part of storylines.

    Buff

    : A temporary positive effect that enhances character abilities (e.g., strength potion).

    C

    Cardinal Direction

    : The four main compass directions: North, South, East, West.

    Character

    : Your player avatar in the game. Has stats, equipment, and progression.

    Class

    : Your character's profession (Warrior, Mage, Rogue, etc.) affecting abilities and playstyle.

    Combat

    : Battle system where players fight enemies using commands like Attack, Defend, and Flee.

    Compact Mode

    : Interface setting that reduces spacing to show more information on screen.

    Console

    : Another term for the Terminal widget where commands are typed and messages appear.

    Consumable

    : An item that is used up when activated (potions, food, scrolls).

    Critical Hit

    : A lucky attack that deals bonus damage, often indicated by special text or effects.

    D

    Damage

    : The amount of harm dealt by attacks. Affected by weapons and attributes.

    Defense

    : A stat that reduces incoming damage. Combat command to take defensive stance.

    Dialog

    : Conversation system with NPCs where you select numbered response options.

    Drop

    : To remove an item from inventory and place it on the ground. Also refers to loot that enemies leave behind.

    E

    Elite Enemy

    : A stronger-than-normal enemy with better loot and higher difficulty.

    Emote

    : A command that expresses an action or emotion (shrug, scream).

    Entity

    : Any character in a room (NPCs, enemies, merchants).

    Equipment

    : Items worn or wielded by your character (armor, weapons, accessories).

    Exit

    : A direction you can travel from your current room.

    Experience Points (XP)

    : Points earned by defeating enemies and completing quests. Accumulate to level up.

    F

    Flee

    : Combat command to attempt escaping from battle.

    G

    Gold

    : The main currency used to buy items and services.

    Grind

    : Repeatedly fighting enemies to gain experience or loot.

    Grid View

    : Inventory display mode showing item thumbnails/icons.

    H

    HP (Hit Points / Health Points)

    : Your character's life force. When it reaches 0, you die.

    Health Bar

    : Visual indicator showing current HP as a colored bar.

    I

    Intelligence

    : Character attribute affecting magic damage and mana pool.

    Inventory

    : The collection of items your character is carrying.

    Item

    : Any object that can be picked up, used, or equipped.

    Item Quality

    : Rarity tier of items (Normal, Magic, Rare, Legendary, Mythic).

    L

    Level

    : A measure of character power and progression. Increases when you gain enough XP.

    List View

    : Inventory display mode showing items as a compact text list.

    Loot

    : Items dropped by defeated enemies or found in the world.

    M

    Merchant

    : An NPC who buys and sells items.

    Minimap

    : A widget that displays a visual map of explored rooms.

    MUD

    : Multi-User Dungeon - A text-based multiplayer online game.

    MUD Client

    : The interface used to play the MUD (what TalesMUD provides).

    N

    NPC (Non-Player Character)

    : A character controlled by the game, not a player.

    O

    Objective

    : A task within a quest that must be completed.

    Overlay

    : A UI element displayed on top of other interface elements (e.g., Room Text Overlay).

    P

    Parchment Background

    : A visual setting that adds a texture to room descriptions.

    Potion

    : A consumable item that restores HP, mana, or provides buffs.

    Preset

    : A pre-configured layout or setting combination.

    Q

    Quest

    : A mission given by an NPC with objectives and rewards.

    Quest Giver

    : An NPC who provides quests.

    Quest Item

    : An item required for a quest that cannot be dropped or sold.

    Quest Log

    : A widget showing all active and completed quests.

    R

    Race

    : Your character's species (Human, Elf, Dwarf, etc.) affecting starting attributes.

    Respawn

    : Returning to life at your bind point after death.

    Room

    : A location in the game world. Each room has a description, name, and exits.

    Room Widget

    : The interface panel showing the current location with image, description, and entities.

    S

    Session Storage

    : Temporary browser storage that resets when the page reloads (used for minimap).

    Slot

    : An equipment position (Head, Chest, Main Hand, etc.).

    Special Exit

    : A non-cardinal direction exit with a custom name (e.g., "enter portal").

    Stack

    : Multiple identical items in a single inventory slot (e.g., "Health Potion x5").

    Stat

    : Short for statistic. Any numerical character attribute.

    Strength

    : Character attribute affecting physical damage and carrying capacity.

    Syntax Highlighting

    : Color-coding of terminal text for improved readability (in Terminal X).

    T

    Terminal

    : The widget where you type commands and see game messages. Two versions: Classic Terminal and Terminal X.

    Toast Notification

    : A temporary message that appears and auto-dismisses (e.g., quest notifications).

    Turn-Based Combat

    : Combat system where players and enemies take alternating actions.

    V

    Vendor

    : Another term for merchant.

    Vertical Movement

    : Going up or down (stairs, ladders, etc.).

    W

    Waypoint

    : A fast-travel location (if implemented in the game).

    Widget

    : A movable, resizable panel in the interface (Room, Terminal, Character, etc.).

    Wilderness

    : Open areas between towns, often with enemies.

    X

    XP Bar

    : Visual indicator showing progress toward the next level.

    xterm.js

    : The terminal emulator library used by the Classic Terminal widget.

    Z

    Z-Level

    : The vertical floor/level in the game world (used by minimap).

    Interface Terms

    localStorage

    : Browser storage that persists across sessions (used for settings and layout).

    Session Storage

    : Browser storage that clears when the page closes (used for minimap).

    Modal

    : A popup dialog that requires interaction before continuing.

    Drawer

    : A panel that slides in from the edge of the screen (mobile).

    Tooltip

    : Small text that appears when hovering over an element.

    Responsive Design

    : Interface that adapts to different screen sizes.

    Gameplay Terms

    Aggro / Aggressive

    : Enemies that attack on sight.

    Passive

    : Enemies that only attack when provoked.

    Farming

    : Repeatedly performing an action to gain resources (similar to grinding).

    Tank

    : A character role focused on defense and absorbing damage (multiplayer).

    DPS

    : Damage Per Second - High damage dealing role (multiplayer).

    Healer

    : A character role focused on healing others (multiplayer).

    PvE

    : Player vs Environment - Fighting computer enemies.

    PvP

    : Player vs Player - Fighting other players (if supported).

    Cooldown

    : Time you must wait before using an ability again (if applicable).

    Proc

    : A special effect that activates randomly or conditionally.

    World Terms

    Zone

    : A distinct area of the game world with a theme and level range.

    Dungeon

    : An enclosed area with high enemy density and often a boss.

    Instance

    : A private copy of an area for a player or group (if applicable).

    Hub

    : A central location that connects to multiple areas (usually a town).

    Safe Zone

    : An area where combat is not possible.

    Quality of Life Terms

    Auto-Save

    : Game progress saved automatically without manual action.

    Auto-Pickup

    : Items automatically added to inventory (e.g., gold).

    Hot Key

    : A keyboard shortcut for an action.

    Macro

    : A sequence of commands executed together (not necessarily supported).

    Bind

    : Assigning a command to a key or button. Also the respawn point command.

    Status Terms

    In Combat

    : Active battle state where movement and some actions are restricted.

    Dead

    : State when HP reaches 0, requiring respawn.

    Stunned

    : Unable to act (if status effects exist).

    Buffed

    : Under the effect of beneficial temporary enhancements.

    Debuffed

    : Under the effect of negative temporary effects.

    Meta Terms

    Meta

    : Information or strategies about the game from outside the game world.

    Min-Max

    : Optimizing character build for maximum effectiveness.

    Metagaming

    : Using out-of-game knowledge to gain advantage.

    Cheese

    : Exploiting game mechanics in unintended ways.

    Nerf

    : Developer reduction of something's power or effectiveness.

    Buff (verb)

    : Developer increase of something's power or effectiveness.
