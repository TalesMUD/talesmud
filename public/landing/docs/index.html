New to MUDs?

If you've never played a MUD (Multi-User Dungeon) before, start with Getting Started. MUDs are text-based adventure games where you type commands to interact with the world. TalesMUD modernizes this classic genre with a graphical interface while keeping the depth and immersion that makes MUDs special.

What is TalesMUD?

TalesMUD is a modern multi-user dungeon (MUD) game that combines classic text-based adventure gameplay with a modern graphical interface. Explore a rich fantasy world, complete quests, battle monsters, collect items, and level up your character.
